# machine-learning-dais32w
Materi ini mendokumentasikan pengembangan materi teori, modul praktikum, dan notebook Python mata kuliah Pembelajaran Mesin (DAIS32W) yang dipetakan ke 11 unit kompetensi Data Scientist berdasarkan SKKNI Nomor 299 Tahun 2020.
Cakupan materi meliputi perumusan masalah, penentuan tujuan teknis, eksplorasi dan validasi data, pembersihan, preprocessing, konstruksi dan seleksi fitur, PCA, pembangunan model, evaluasi, serta review pemodelan. Praktikum menggunakan dataset UCI Air Quality, data simulasi, dan dataset scikit-learn untuk mempelajari statistika, optimisasi, generalisasi, regularisasi, data leakage, class imbalance, dan interpretabilitas. Portofolio didukung modul pembelajaran, kode Python, serta hasil eksekusi notebook yang terdokumentasi.
